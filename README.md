# Step Tech Shop

A responsive e-commerce web application built with Angular as part of my studies at IT Step Academy.

The project was based on a provided design, which I recreated as closely as possible and then made functional using the provided API.

## Live Demo

[View the deployed website](https://steptechshop.vercel.app/)

## About the Project

Step Tech Shop is an online shop created to practice building a real-world frontend application with Angular.

The project includes a product-based shopping experience and uses an API to provide functional application data.

## Technologies

* Angular
* TypeScript
* HTML5
* SCSS
* REST API

## What I Practiced

* Building an application with Angular
* Creating reusable components
* Working with APIs
* Managing application data
* Styling with SCSS
* Building responsive layouts
* Structuring a frontend application
* Working with TypeScript
* Recreating a provided UI design
